# Native Continuous Planner

Production C++20 engine, public headers, runtime model bundles and native regression tests. Public include: `<abcurves/native.hpp>`. The model directory selects the 32/16/8 ms variant. Optional original Renderer source remains in `Native/runtime/c/`.

Use the [root build](../docs/getting-started/building.md) for the full multilingual SDK; `cmake -S lib` remains the engine-only entry. Current guides: [integration](../docs/integration.md), [models/architecture](../docs/quick-start.md#1-choose-a-model), [API](../docs/api/overview.md). Runtime semantics and model bytes are unchanged by publication preparation.
