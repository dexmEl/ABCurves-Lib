# ABCurves language interfaces

Start with the [Quick Start](../docs/quick-start.md), then choose [C++](../docs/getting-started/cpp.md), [C](../docs/getting-started/c.md), [Python](../docs/getting-started/python.md), or [Rust](../docs/getting-started/rust.md).

Use a Model, Planner, and SegmentController for normal integration. [Application integration](../docs/integration.md) explains targets, movement samples and timing; [examples](../examples/README.md) contains runnable commands. Advanced functions remain available through the [advanced reference](../docs/advanced/README.md).

The stable C ABI is 1.5 and retains 1.4 compatibility. Build entry points `cmake -S .`, `cmake -S API`, and `cmake -S lib` remain supported.
