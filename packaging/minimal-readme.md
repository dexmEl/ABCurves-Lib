# ABCurves Windows x64 runtime

Place `abcurves.dll` beside your application. It includes all three planner
models and the Renderer model. Windows x64 and the Microsoft Visual C++ x64
runtime are required.

Obtain the C, C++, Python, or Rust interface and examples from the
[ABCurves repository](https://github.com/dexmEl/ABCurves-Lib) or the matching
Windows SDK release archive. The Windows Python wheel includes its own DLL.
