# ABCurves 1.5.1

This patch release adds an AI-assisted integration workflow and includes the updated documentation in the Windows SDK download.

## Changes

- Include `AGENTS.md` and the public documentation guides in the full Windows SDK ZIP, covering model selection, calibration, language setup and local integration validation.
- Add the public documentation MCP at https://mcp.nanoed.net/abcurves, with setup commands for Codex CLI and Claude Code. The agent implements and tests in the user's project.
- Recommend 32 ms as the starting model and clarify the 8/16/32 ms trade-offs and the limits of existing comparisons. All three produce 1 ms samples.
- Correct embedded-model installation guidance, Rust DLL discovery instructions and the installed CMake example.
- Fix the C++ DLL raw-history example to initialize the planner with the returned filtered anchor, with regression coverage using a nonzero prefix.
- Align the CMake, Python and Rust package versions at 1.5.1. The C ABI remains 1.5; planner algorithms, model weights and Renderer math are unchanged.

## Downloads

- `abcurves-windows-x64-sdk.zip`: DLL, C/C++/Python/Rust interfaces, examples, `AGENTS.md` and offline documentation.
- `abcurves-windows-x64.zip`: minimal DLL, license notices and short README.
- `abcurves_native-1.5.1-py3-none-win_amd64.whl`: Python binding with the embedded-model Windows DLL.
- `SHA256SUMS.txt`: SHA-256 checksums for the three packages.

Windows x64 and the compatible Microsoft Visual C++ runtime are required. No PyPI or crates.io publication is included.
